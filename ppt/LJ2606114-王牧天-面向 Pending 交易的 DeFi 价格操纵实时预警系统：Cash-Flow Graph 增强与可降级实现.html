Literature · Method Families

LITERATURE REVIEW

已有方法在可解释性、泛化和时效性之间取舍

本文继承规则与 Cash-Flow Graph 思路，但把系统目标放在 pending 阶段。

ATransparent
规则 / 语义检测

代表：DeFiRanger。优势是证据清楚、可运营；局限是对未知攻击和跨交易变种覆盖不足。

  • 原因码明确
  • 规则维护成本高
  • 高精度依赖 trace / 价格 / 流动性数据
BGeneralize
图神经网络 / 商业服务

代表：DeFiGuard、STA-GT、CertiK、SlowMist。图学习泛化更强，商业服务覆盖广，但多数偏事后或方法不透明。

  • 适合跨地址泛化
  • 时序模型延迟更高
  • pending trace 仍是缺口

Algorithm · Profit Path
13 / 20
PROFIT PATH

利润路径分析刻画异常净流入

仅对上游已经提供 value_usd 的资金边计分，并排除闪电贷 borrow / repay 腿。

Formula
profit_path_score = Σ inflow_value_usd − Σ outflow_value_usd max(1, Σ outflow_value_usd)
  • 净流入比率 0.30 开始触发
  • 达到 0.50 时取得满规则分
  • 价格字段缺失时该规则不触发
  • FlashLoan borrow / repay 排除
  • 不在评分器内臆造代币价格
  • 触发详情写入 rule_scores

RAG COLD PATH

解释风险
不是替代评分

RAG 不进入热路径，也不参与风险分数；高危告警先发分数版，再异步补解释。

async non-scoring auditable
DENSE

确定性哈希向量

64 维本地向量，无外部 Embedding 依赖。

SPARSE

词项计数检索

协议、章节、等级与正文共同形成稀疏词项。

FUSION

RRF + 固定模板

融合排序后生成可复现解释，不调用外部 LLM。

触发条件
high / critical 告警进入异步解释队列；低风险交易只保留结构化风险分。
输出字段
graph_summary、doc_summary、analyst_note 与 evidence_refs 分开生成。
约束
解释不能反向修改分数；LABEL 不写成身份定论，避免误导复核。

19 / 20
